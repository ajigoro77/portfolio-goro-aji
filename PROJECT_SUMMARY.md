# Portfolio Goro Aji - Project Summary

## Overview
A modern, AI-enhanced personal portfolio website built with Next.js 15, React 19, Tailwind CSS v3, and shadcn-ui for Goro Aji, S.Kom.

## Tech Stack
- **Next.js 15** with App Router
- **React 19**
- **Tailwind CSS v3** (downgraded from v4 for Node.js 20 compatibility)
- **shadcn-ui** components
- **Framer Motion** for animations
- **Groq** via Vercel AI SDK for chatbot (with model fallback system)
- **npm** package manager
- **TypeScript** for type safety

## Data Configuration
All content driven by **`portfolio-config.json`** - no hardcoded content in components. Edit the JSON to update everything.

### Configuration Sections:
- `personal` - name, location, title, bio, avatar
- `skills` - 7 categories: programming, ml_ai, web_development, databases, devops_cloud, iot_hardware, soft_skills
- `certifications` - list of certifications with issuer, period, description
- `projects` - featured projects with tech stacks, links, images, status, achievements
- `education` - S1 Teknik Informatika UNINDRA, RevoU certification
- `experience` - work/project experience with company, position, duration, technologies
- `social` - LinkedIn, GitHub, Twitter, Kaggle, LeetCode, Fiverr URLs
- `internship` - job seeking status, focus areas, availability, work style, goals
- `personality` - traits, interests, fun facts, working style, motivation
- `resume` - title, description, file type, size, last updated, download URL
- `chatbot` - AI persona, tone, language, response style, emoji usage, topics
- `presetQuestions` - Quick-start conversation starters (me, professional, projects, contact, fun)
- `meta` - config version, last updated, generated by, description

- Resume download button

### 8. AI Chatbot ("Goro")
- **Tool-based AI** using Groq
- Uses config data for accurate responses
- **Model fallback system**: If one model fails (e.g., rate limit, not found), automatically tries next model
- Supported models: `openai/gpt-oss-20b`, `openai/gpt-oss-120b`, `llama-3.1-8b-instant`, `llama-3.1-8b`
- 6 tool types: getPresentation, getSkills, getProjects, getResume, getContact, getInternship
- Preset questions for quick interaction
- Personality: professional, friendly, tech-savvy
- Response style: short, interactive, uses emojis
- Topics: projects, skills, education, certification, contact
- Visual tool rendering in chat (components displayed directly when tools are called)
- Preset replies (non-AI responses to save API quota)
- "Get AI Response" button to upgrade preset replies to AI-generated answers

### 9. Additional
- Light/dark theme support
- Full SEO metadata (Open Graph, Twitter Cards)
- Sitemap.xml and robots.txt

## How to Run

```bash
npm install
cp .env.example .env.local  # Add GROQ_API_KEY (free at https://console.groq.com/keys)
npm run dev   # Development server
npm run build # Build for production
```

### Environment Variables (`.env.local`)
```env
GROQ_API_KEY=your_groq_api_key_here
GROQ_MODEL=openai/gpt-oss-20b
GROQ_FALLBACK_MODELS=openai/gpt-oss-20b,openai/gpt-oss-120b,llama-3.1-8b-instant,llama-3.1-8b
NEXT_PUBLIC_SITE_URL=http://localhost:3000
```

## Customization
- **Update content**: Edit `portfolio-config.json`
- **Replace assets**: Update `public/profile.png`, add `resume-goro-aji.pdf`
- **Chatbot settings**: Modify chatbot section in config
- **Add projects**: Add entries to projects array in config
- **Change AI model**: Edit `GROQ_MODEL` and `GROQ_FALLBACK_MODELS` in `.env.local`

## Known Issues / Notes
- Tailwind CSS v4 was incompatible with Node.js 20 (ERR_REQUIRE_ESM with magic-string), downgraded to v3
- If AI chatbot shows "API Notice", ensure `GROQ_API_KEY` is set correctly in `.env.local` and server is restarted
- If model error appears, the fallback system will automatically try alternative models
- Some Framer Motion variant types require `as any` cast due to TypeScript/Framer Motion version mismatch (non-blocking, build succeeds)
